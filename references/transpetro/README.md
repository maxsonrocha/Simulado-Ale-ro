# Base normativa — Transpetro 2026

Este diretório é a base de referência para criação e auditoria das questões de Engenharia de Segurança do Trabalho.

## Regra de uso

1. Para questões normativas, legais, previdenciárias ou de higiene ocupacional, não usar memória do modelo como fonte primária.
2. Verificar a afirmação na fonte oficial indicada neste índice antes de criar a questão.
3. Se a fonte oficial estiver inacessível no ambiente de execução, não inventar item, artigo, prazo, limite, obrigação, exceção ou valor.
4. Em conflito entre material antigo e texto vigente, prevalece o texto oficial vigente na data de consulta.
5. Registrar no relatório do lote qualquer questão normativa que não pôde ser criada por falta de verificação.
6. NR-2 e NR-27 são revogadas e não devem ser tratadas como NRs vigentes.
7. Para a NR-1/GRO/PGR, usar a redação vigente desde 26/05/2026 e os materiais interpretativos de 2026 do MTE.

## 11. ISO 45001, ISO 14001 e ISO 19011

Essas normas possuem conteúdo protegido por direitos autorais. Não armazenar nem reproduzir integralmente seus textos neste repositório sem autorização.

As questões podem avaliar conceitos e aplicações compatíveis com o conteúdo programático, mas não devem reproduzir trechos extensos ou inventar cláusulas. Quando uma questão depender de numeração exata de cláusula ou redação específica, exigir uma fonte licenciada/verificável.

## 12. Convenções da OIT

Quando o conteúdo programático exigir Convenções da OIT, verificar o texto oficial e o status de ratificação aplicável ao Brasil antes da questão.

Portal oficial OIT:
https://www.ilo.org/

Não presumir ratificação ou vigência apenas pelo número da Convenção.

## Checklist obrigatório para questão normativa

Antes de aprovar uma questão, confirmar:

- [ ] fonte oficial identificada;
- [ ] texto vigente na data de referência;
- [ ] nenhuma norma revogada tratada como vigente;
- [ ] item/artigo conferido quando citado;
- [ ] prazo conferido;
- [ ] valor/limite conferido;
- [ ] exceções relevantes consideradas;
- [ ] exatamente uma alternativa defensável;
- [ ] explicação compatível com a fonte;
- [ ] questão não duplica nem parafraseia item existente;
- [ ] cálculo refeito independentemente, quando houver.

## Política para erro 403

Erro HTTP 403 no ambiente do Codex não autoriza usar memória do modelo como substituição.

Quando ocorrer:
1. tentar a página índice oficial ou outra representação oficial do mesmo documento;
2. usar material oficial já registrado/localizado nesta base;
3. se ainda não for possível verificar o ponto específico, não gerar a questão;
4. registrar a pendência no relatório do lote.

A prioridade é correção normativa, não quantidade.
